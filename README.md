# Interconexões em Psicologia

Blog acadêmico desenvolvido para a disciplina Interconexões em Psicologia, com foco em prática rizomática, integração entre subáreas da Psicologia e crítica ao integracionismo vazio.

## Estrutura

- Página inicial com apresentação do tema
- Três postagens explicativas
- Postagem final autoral
- Infográfico conceitual
- Manifesto do rizoma
- Referências bibliográficas
- Seção de integrantes do grupo

## Tecnologias

- HTML
- CSS
- JavaScript

O projeto é estático e pode ser publicado em serviços como GitHub Pages, Netlify ou Vercel.
